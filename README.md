# Kitchen Chaos Multiplayer

A multiplayer version of Kitchen Chaos created in Unity using Netcode for GameObjects.

## Features

- Two-player multiplayer
- Networked player spawning
- Synchronized player movement
- Networked player interactions

## Built With

- Unity 2022.2.7f1
- C#
- Unity Netcode for GameObjects
